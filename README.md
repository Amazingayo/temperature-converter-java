# Temperature Converter 

A simple, interactive console-based Java application that converts temperatures between Celsius and Fahrenheit. 

## Features
- **Celsius to Fahrenheit:** Accurately converts Celsius inputs to Fahrenheit using the standard formula `(C * 9/5) + 32`.
- **Fahrenheit to Celsius:** Accurately converts Fahrenheit inputs to Celsius using the standard formula `(F - 32) * 5/9`.
- **Decimal Support:** Accepts double data types for precise, real-world temperature measurements.
- **Interactive UI:** Utilizes a simple command-line menu for easy navigation.

## How to Run

1. Ensure you have the Java Development Kit (JDK) installed on your system.
2. Clone this repository to your local machine:
   ```bash
   git clone [https://github.com/Amazingayo/temperature-converter-java.git](https://github.com/Amazingayo/temperature-converter-java.git)
   ```
3. Navigate to the project directory and compile the Java file:
   ```bash
   javac TemperatureConverter.java
   ```
4. Run the compiled application:
   ```bash
   java TemperatureConverter
   ```

## Technologies Used
- **Java:** Core logic and console I/O (`java.util.Scanner`).
